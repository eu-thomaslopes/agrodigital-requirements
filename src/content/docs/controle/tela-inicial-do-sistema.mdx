## 1. Exibir tela inicial do sistema

**Dado que** estou em um computador com acesso à internet  
**Quando** acesso o endereço web do sistema  
**Então** o sistema exibe a tela inicial com os campos a seguir.

```componente
componente: Informar CPF
```

| Campo | Tipo | Obrigatório | Validações | Exemplo | Valor padrão |
| --- | --- | :---: | --- | --- | --- |
| Senha | Texto | Sim | Alfanumérico.<br />Tamanho máximo = 70 caracteres. | `Exemplo@1` | Vazio |

| Ação | Comportamento |
| --- | --- |
| Entrar com CPF | Realiza a autenticação com CPF e senha (US010). |
| Esqueceu a senha? | Abre a recuperação de senha (US011). |
| Criar uma nova conta com CPF | Abre o cadastro de usuário com CPF (US012). |
| Entrar com GOV.BR | Inicia a autenticação ou o cadastro via GOV.BR (US010 e US012). |
