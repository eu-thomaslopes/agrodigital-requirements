## 1. Autenticar com CPF e senha

**Dado que** estou na tela inicial do sistema (US009), com os campos de CPF e senha definidos nessa história  
**Quando** realizo a ação **Entrar com CPF**  
**E** todos os campos obrigatórios estão preenchidos corretamente  
**E** as credenciais correspondem às de um usuário cadastrado  
**Então** o sistema realiza o login e exibe a tela para usuários autenticados, de acordo com o perfil do usuário.

| Cenário de erro | Comportamento |
| --- | --- |
| Campos válidos, mas credenciais incompatíveis com o cadastro | Não realiza o login e exibe `CPF/senha inválidos`. |
| Campos obrigatórios ausentes ou preenchidos incorretamente | Não realiza o login.<br />Destaca os campos ausentes ou com erro e apresenta uma mensagem indicando os problemas. |

## 2. Autenticar com GOV.BR

**Dado que** estou na tela inicial do sistema (US009)  
**Quando** realizo a ação de acesso ou cadastro com GOV.BR  
**Então** o sistema trata o retorno da autenticação da seguinte forma:

| Cenário | Comportamento |
| --- | --- |
| Autenticação GOV.BR bem-sucedida e usuário já cadastrado no sistema utilizando GOV.BR | Realiza o login e exibe a tela para usuários autenticados, de acordo com o perfil do usuário. |
| Autenticação GOV.BR bem-sucedida e usuário sem cadastro no sistema utilizando GOV.BR | Não realiza o login e exibe o cadastro de usuário com GOV.BR (US012). |
| Falha na autenticação GOV.BR | Não realiza o login e exibe `A autenticação falhou`. |
